# Portfolio Website - Anthony Luebbe

## Design Planning & Specification

### 1. Conceptual Site Map

- **Home Page** (Implemented Phase I)
  - Hero Banner (Name, Title, Headshot Image, Professional Summary)
  - Developer Focus Areas (Frontend, Backend & Databases, Version Control & Cloud Deployment)
- **Career Focus / Skills** (Planned Phase II)
  - Tech Stack & Proficiency Overview
  - Central Community College Coursework & Systems Training
- **Projects / Portfolio** (Planned Phase III)
  - Web & Software Project Showcase with Live Links and GitHub Repositories
- **Contact & Resume** (Planned Phase IV)
  - Contact Form, Professional Links, and Downloadable Resume

### 2. Page Layout Strategy

- **Navigation Header:** Clean top navbar containing branding (`Anthony Luebbe`) and navigation links (`Home`, `Career Focus`).
- **Hero Banner:** Two-column responsive layout featuring a circular profile card with headshot on the left and introductory copy on the right.
- **Content Sections:** Responsive card grid highlighting core technical focus areas.
- **Footer / Base:** Uncluttered layout designed for responsive scaling across mobile, tablet, and desktop views.

### 3. Color Palette

- **Primary Brand / Accent:** `#2563eb` (Royal Blue - used for primary headings, focus highlights, and active nav links)
- **Primary Text:** `#1e293b` (Dark Slate/Charcoal - high contrast for main reading copy)
- **Background Canvas:** `#f8fafc` (Off-White/Light Gray - clean page background)
- **Card & Container Background:** `#ffffff` (Pure White - elevated content cards)
- **Borders & Dividers:** `#e2e8f0` (Soft Gray - subtle section card borders)
